# Manual Mobile Checks

Use this checklist on a real phone before release.

## Visual and navigation

- Open the site on iPhone Safari and Android Chrome.
- Verify the header, bottom spacing, and sticky actions on the main pages.
- Check that no horizontal scroll appears on:
  - Home
  - Annonces
  - Annonce detail
  - Publier
  - Messages
  - Pro
- Open a few pages with the keyboard visible and confirm nothing is hidden behind the browser chrome.

## Core user flows

- Create a message and send a photo.
- Publish an announcement with at least one image.
- Edit a draft and confirm the save state is visible.
- Open a Pro dashboard listing and verify the cards do not feel cramped.
- Open the mobile ticketing flow and confirm the QR code is readable.
- Verify the coupon / promo pages still fit on a narrow screen.

## Media and uploads

- Upload several photos from the camera roll.
- Confirm image compression happens before submit.
- Check that uploaded previews remain tappable.
- Verify the PDF viewer can be scrolled and zoomed without layout breakage.

## Forms and accessibility

- Make sure form inputs do not auto-zoom on iOS.
- Check the keyboard does not cover the main CTA buttons.
- Confirm select menus and date pickers remain usable with one hand.

## Ticketing and commerce

- Create or open an event with ticketing.
- Reserve a ticket and verify the confirmation screen.
- Check the QR scan screen is usable in both portrait and landscape.
- Confirm push notification permission prompts do not block the first action.

## Done criteria

- No clipped text.
- No broken tap targets.
- No frozen navigation after returning from the keyboard.
- No layout shift that hides the CTA.
